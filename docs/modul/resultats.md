# Resultats d'aprenentatge i criteris d'avaluació

## Què són i per què importen

Cada mòdul de formació professional es divideix en **resultats d'aprenentatge** (RA): què
heu de *saber fer* en acabar. I cada RA es desglossa en **criteris d'avaluació** (CA), que
són els que s'utilitzen per a comprovar si ho sabeu fer.

``` mermaid
graph LR
  A[Resultat d'aprenentatge<br>Què has de saber fer] --> B[Criteri d'avaluació<br>Com ho comprovem]
  B --> C[Activitat<br>Com ho treballem a classe]
```

Un exemple concret d'aquest mòdul:

| | |
| --- | --- |
| **RA3** | Identifica sistemes basats en el núvol i la seua influència en el desenvolupament dels sistemes digitals. |
| **CA 3c** | S'ha descrit el concepte d'*edge computing* i la seua relació amb el núvol. |
| **Activitat** | Decidir quines dades dels sensors de reg de Tarongina es processen al camp i quines al núvol. |

Conéixer-los us serveix per a tres coses:

- **Orientació.** Sabeu exactament què s'espera de vosaltres.
- **Autoavaluació.** Podeu comprovar el vostre progrés i on heu de millorar.
- **Transparència.** Sabeu com sereu avaluats, sense sorpreses al final.

!!! warning "Regla bàsica"
    Per a superar el mòdul cal tindre **tots els resultats d'aprenentatge assolits**. No
    es compensa un RA suspés amb un altre aprovat.

## Els sis resultats d'aprenentatge

=== "RA1 · Digitalització i entorns IT/OT"

    **Analitza el concepte de digitalització i la seua repercussió en els sectors
    productius, tenint en compte l'activitat de l'empresa i identificant entorns IT
    (*Information Technology*) i OT (*Operation Technology*) característics.**

    Es treballa a la [U01](../u01/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'ha descrit en què consisteix el concepte de digitalització. |
    | b | S'ha relacionat la implantació de la tecnologia digital amb l'organització de les empreses. |
    | c | S'han establit les diferències i semblances entre els entorns IT i OT. |
    | d | S'han identificat els departaments típics de les empreses que poden constituir entorns IT. |
    | e | S'han seleccionat les tecnologies típiques de la digitalització en planta i en negoci. |
    | f | S'ha analitzat la importància de la connexió entre entorns IT i OT. |
    | g | S'han analitzat els avantatges de digitalitzar una empresa industrial d'extrem a extrem. |

=== "RA2 · Tecnologies habilitadores"

    **Caracteritza les tecnologies habilitadores digitals necessàries per a
    l'adequació o transformació de les empreses a entorns digitals, descrivint-ne les
    característiques i aplicacions.**

    Es treballa a la [U02](../u02/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'han identificat les principals tecnologies habilitadores digitals. |
    | b | S'han relacionat les THD amb el desenvolupament de productes i serveis. |
    | c | S'ha relacionat la importància de les THD amb l'economia sostenible i eficient. |
    | d | S'han identificat nous mercats generats per les THD. |
    | e | S'ha analitzat la implicació de les THD tant en la part de negoci com en la de planta. |
    | f | S'han identificat les millores produïdes per la implantació de les THD en relació amb els entorns IT i OT. |
    | g | S'ha elaborat un informe que relacione les tecnologies amb les seues característiques i àrees d'aplicació. |

=== "RA3 · Núvol"

    **Identifica sistemes basats en el núvol (*cloud*) i la seua influència en el
    desenvolupament dels sistemes digitals.**

    Es treballa a la [U05](../u05/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'han identificat els diferents nivells del núvol. |
    | b | S'han identificat les principals funcions del núvol (processament de dades, intercanvi d'informació, execució d'aplicacions, entre altres). |
    | c | S'ha descrit el concepte d'*edge computing* i la seua relació amb el núvol. |
    | d | S'han definit els conceptes de *fog* i *mist* i les seues zones d'aplicació en el conjunt. |
    | e | S'han identificat els avantatges que proporciona la utilització del núvol en els sistemes connectats. |

=== "RA4 · Intel·ligència artificial"

    **Identifica aplicacions de la IA en entorns del sector on està emmarcat el títol,
    descrivint les millores implícites en la seua implementació.**

    Es treballa a la [U03](../u03/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'ha identificat la importància de la IA en l'automatització de processos i la seua optimització. |
    | b | S'ha relacionat la IA amb la recollida massiva de dades (Big Data) i el seu tractament amb la rendibilitat de les empreses. |
    | c | S'ha valorat la importància present i futura de la IA. |
    | d | S'han identificat els sectors amb una implantació més rellevant de la IA. |
    | e | S'han identificat els llenguatges de programació en IA. |
    | f | S'ha descrit com influeix la IA en el sector del títol. |

=== "RA5 · Dades i seguretat"

    **Avalua la importància de les dades, així com la seua protecció en una economia
    digital globalitzada, definint sistemes de seguretat i ciberseguretat tant a nivell
    d'equip o sistema com globals.**

    Es treballa a la [U04](../u04/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'ha establit la diferència entre dada i informació. |
    | b | S'ha descrit el cicle de vida de la dada. |
    | c | S'ha identificat la relació entre Big Data, anàlisi de dades, *machine/deep learning* i IA. |
    | d | S'han descrit les característiques que defineixen el Big Data. |
    | e | S'han descrit les etapes típiques de la ciència de dades i la seua relació en el procés. |
    | f | S'han descrit els procediments d'emmagatzematge de dades en el núvol. |
    | g | S'ha descrit la importància del *cloud computing*. |
    | h | S'han identificat els principals objectius de la ciència de dades en les diferents empreses. |
    | i | S'ha valorat la importància de la seguretat i la seua regulació en relació amb les dades. |

=== "RA6 · Projecte"

    **Desenvolupa un projecte de transformació digital d'una empresa d'un sector
    relacionat amb el títol, tenint en compte els canvis que s'han de produir en funció
    dels objectius de l'empresa.**

    Es treballa a la [U06](../u06/index.md) i és el [projecte final](../projecte/index.md).

    | | Criteri d'avaluació |
    | --- | --- |
    | a | S'han identificat els objectius estratègics de l'empresa. |
    | b | S'han identificat i alineat les àrees de producció/negoci i de comunicacions. |
    | c | S'han identificat les àrees susceptibles de ser digitalitzades. |
    | d | S'ha analitzat l'encaix de les àrees digitalitzades entre si i amb les que no ho estan. |
    | e | S'han tingut en compte les necessitats presents i futures de l'empresa. |
    | f | S'ha relacionat cadascuna de les àrees amb la implantació de les tecnologies. |
    | g | S'han analitzat les possibles bretxes de seguretat en cadascuna de les àrees. |
    | h | S'ha definit el tractament de les dades i la seua anàlisi. |
    | i | S'ha tingut en compte la integració entre dades, aplicacions i plataformes que les suporten. |
    | j | S'han documentat els canvis realitzats en funció de l'estratègia. |
    | k | S'ha tingut en compte la idoneïtat dels recursos humans. |

!!! note "Sobre el text dels criteris"
    Els criteris estan traduïts al valencià a partir del currículum bàsic estatal (annex
    VII del RD 659/2023). En cas de dubte, el text de referència és el publicat al
    *Diari Oficial de la Generalitat Valenciana*.
