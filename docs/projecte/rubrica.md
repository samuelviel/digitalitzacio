# Rúbrica d'avaluació del projecte

El projecte cobreix **tot el RA6**. Cada criteri d'avaluació s'observa en una part concreta
del document o de l'exposició.

!!! warning "Recordatori"
    Per a superar el mòdul cal tindre **tots els resultats d'aprenentatge assolits**. El
    projecte és l'única evidència del RA6: si no s'assoleix ací, no s'assoleix.

## Nivells d'assoliment

| Nivell | Què significa |
| --- | --- |
| **Excel·lent** | Supera el que es demanava. Aporta criteri propi i el defén amb solidesa |
| **Assolit** | Compleix el que es demanava de manera correcta i justificada |
| **En procés** | Hi és, però incomplet, superficial o sense justificar |
| **No assolit** | No hi és o és incorrecte |

## Aportació individual

A més del resultat de l'equip, s'observa l'aportació de cada persona a través de:

- El **tauler de seguiment** (qui ha fet què i quan).
- La **intervenció en l'exposició** sobre el seu rol.
- Les **respostes a les preguntes** del torn final.

!!! info "Nota d'equip i nota individual"
    La base és la nota de l'equip. Es pot ajustar individualment a l'alça o a la baixa
    quan hi haja evidències clares d'una aportació molt superior o molt inferior a la de
    la resta.
